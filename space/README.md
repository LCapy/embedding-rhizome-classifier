# Coredrill - Rhizome Text Classifier

Geometry-native multilingual text classification over a 251-node rhizomatic taxonomy. Maps any text, in any of the 109 languages supported by LaBSE, to a rhizome profile of activated semantic territories.

API docs are at `/docs` once the Space is running.

This Space is deployed from [github.com/LCapy/embedding-rhizome-classifier](https://github.com/LCapy/embedding-rhizome-classifier), which has the documentation. Change it there, not here: the next deploy replaces these files.
