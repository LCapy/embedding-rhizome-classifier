The bar under each block is the size of its gradient in this step: how hard it is being pushed to change.

Attention: query × key

Each row of the query matrix meets each column of the key matrix. Their product, divided by 8 and normalized along the row, says how much one token looks at another. The GPU fills every cell at once; the sweep walks through them so you can follow. Hover over the result to pick a cell.

Which label? text vectors × label vectors

Every text in the batch (rows) is multiplied by every label's vector (columns). A redder cell is a better match. The outlined cell in each row is the correct label: training pushes it up and the rest of the row down.
